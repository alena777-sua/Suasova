#Журнал событий устройства
##Назначение системы
Проект предназначен для хранения и анализа событий, поступающих от интеллектуальных устройств. Система позволяет отслеживать включение, выключение, показания датчиков и ошибки устройств.

##Структура базы данных
База данных состоит из двух таблиц.

###Таблица devices
device_id — идентификатор устройства, первичный ключ
name — название устройства
location — расположение устройства
###Таблица events
event_id — идентификатор события, первичный ключ
device_id — идентификатор устройства, внешний ключ
event_time — время события
event_type — тип события
value — числовое значение показания
Типы событий:

включение
выключение
показание
ошибка
##Порядок развёртывания
Создать базу данных и таблицы: sqlite3 shop_devices.db < schema.sql
Загрузить тестовые данные: sqlite3 shop_devices.db < data.sql
Выполнить запросы мониторинга и диагностики: sqlite3 -header -column shop_devices.db < queries.sql
##Результат диагностики
Термостат-01 сообщает об ошибках чаще остальных устройств: у него обнаружено две ошибки. В первую очередь стоит проверить именно Термостат-01. Датчик-02 и Термостат-03 ошибок не имеют.
